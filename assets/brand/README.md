# Activos oficiales LAYOUTM

Esta carpeta está reservada para los archivos gráficos oficiales aprobados de LAYOUTM.

Pendientes de incorporar desde los archivos originales:

- versión principal: lettering LAYOUTM y símbolo gráfico;
- versión extendida: lettering LAYOUTM, símbolo gráfico, línea divisoria y las frases “carpintería inteligente” y “detalles que conectan”.

No se deben reconstruir, calcar ni reinterpretar estos activos. Cuando se reciba el archivo principal, se deberá guardar sin alterar su composición y registrar su ruta en el atributo `data-brand-logo-src` del brand reveal en `index.html`.
