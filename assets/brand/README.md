# Activos oficiales LAYOUTM

Esta carpeta conserva las imágenes oficiales suministradas para el HOME de LAYOUTM:

- `layoutm-logo-principal.png`: versión principal con lettering LAYOUTM y símbolo gráfico. Se utiliza en el brand reveal.
- `layoutm-logo-extendido.jpeg`: versión extendida con lettering, símbolo, línea divisoria, “carpintería inteligente” y “detalles que conectan”.

Ambos archivos se guardan sin alterar sus píxeles, proporciones ni composición. No se deben reconstruir, calcar ni reinterpretar. La versión extendida queda disponible como referencia oficial y no se muestra todavía en el HOME.
